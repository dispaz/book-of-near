# Topic 5.2: Autonomous Shade Agents (TEE Agents Controlling Multichain Keys)

## In one sentence

By running an autonomous AI agent inside a hardware TEE enclave that directly generates and manages Chain Signature keys, an AI agent can own and operate accounts across any blockchain with no human master holding a backdoor key.

## The problem it solves

Most Web3 "AI agents" today are glorified bots: a human developer runs Python code on an AWS server and holds the private wallet keys in a `.env` file. If the developer gets hacked, goes rogue, or is subpoenaed, the agent's funds and autonomous behavior can be seized or manipulated instantly. The agent is not truly autonomous—it is merely an automated human delegate. [shade-agents]

## How it works on NEAR

**The Union of TEEs and Chain Signatures.**
- An agent's core decision-making loop runs completely inside a Trusted Execution Environment (Intel TDX / AMD SEV). [shade-agents]
- Using **Chain Signatures** (Topic 4.1), the agent requests a derived multichain account through NEAR's MPC network (`v1.signer`). [near-chain-sigs]
- The agent's derived address is tied deterministically to the enclave's code hash (its attestation measurement). [shade-agents]

**Zero Human Backdoor.**
- The enclave generates its internal entropy and state within hardware memory. [tee-overview]
- Because nobody has root access to the enclave memory (the triple lockout from Topic 5.1), **no human developer possesses the private keys**. [shade-agents]
- The agent can receive funds, analyze market conditions, interact with smart contracts on NEAR, swap on Solana, or arbitrage on Arbitrum purely based on its internal open-source logic. [shade-agents]

**Verifiable Upgrades & Governance.**
- If an autonomous agent needs a code upgrade, it cannot be arbitrarily patched by a single developer. [shade-agents]
- The enclave's state migration can be governed by a decentralized smart contract or DAO on NEAR. [near-daos]
- A new version of the agent code produces a new hardware measurement, which must be approved on-chain before existing state and identity are transferred. [shade-agents]

## Words to know

- **Shade Agent:** An autonomous AI agent running inside a hardware-isolated enclave with direct control over blockchain accounts.
- **Autonomous Key Custody:** When an AI agent exclusively holds the cryptographic credentials to authorize blockchain transactions.
- **Agentic Finance (AgentFi):** Financial applications and market strategies designed and executed autonomously by AI agents.
- **Un-owned Account:** An account controlled solely by program execution within an enclave rather than an individual human's seed phrase.

## Common misunderstandings

- **"An AI agent can rewrite its own code to become malicious."** The agent's binary executable is locked in the TEE. Modifying code produces a different measurement hash, instantly revoking its access to the on-chain identity and funds. [shade-agents]
- **"Shade agents only work on NEAR."** By using NEAR Chain Signatures, an agent inside an enclave can sign transactions on Ethereum, Bitcoin, Solana, and Cosmos seamlessly. [near-chain-sigs]
- **"The developer can always pull the plug."** The physical host can turn off power to the machine, but cannot steal the funds or forge the agent's signature. If the agent's state is backed up to decentralized storage, it can be spun up on a different physical TEE node. [shade-agents]

## Compared with Traditional Bots & Smart Contract Wallets

- **Standard Trading Bots:** Run on standard servers; keys stored in plaintext or environment variables; fully susceptible to operator theft and cloud compromises. [shade-agents]
- **Smart Contract Agents (Autonolas):** Logic is bound to on-chain smart contract bytecode; expensive to run complex LLMs on-chain; limited to chains with smart contract execution. [autonolas]
- **NEAR Shade Agents:** Can run heavy modern LLMs inside confidential compute clusters off-chain while maintaining un-hackable multichain key control via NEAR MPC. [shade-agents]

## Strengths and weaknesses (feeds the Honest take)

**Strengths:**
- True agent autonomy: Zero human backdoors; keys cannot be extracted even under physical coercion. [shade-agents]
- Multichain execution: A single TEE agent manages wallets on Bitcoin, Ethereum, and Solana through NEAR Chain Signatures. [near-chain-sigs]
- Complex off-chain reasoning: Can execute modern LLMs and complex heuristics without paying prohibitive on-chain gas costs for every internal reasoning step. [near-ai-vision]

**Weaknesses:**
- Enclave availability risk: If the physical server hosting the enclave goes offline without a multi-node redundant enclave consensus, agent execution pauses. [tee-overview]
- Determinism challenges: Non-deterministic LLM sampling can cause replicas to diverge unless seeds and temperature are strictly controlled. [shade-agents]
