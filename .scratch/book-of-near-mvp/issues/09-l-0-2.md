# 09: Lesson 0.2: Make a wallet

**What to build:** The learner generates a key pair and a seed phrase in the browser, sees how an address is derived from a public key, signs a message, verifies it, then changes one letter and sees verification fail. The lesson clearly says to use only throwaway keys and never to enter a real seed phrase anywhere. It compares address styles briefly (hash of a public key versus NEAR's hex and named accounts) and ends with an honest take.
