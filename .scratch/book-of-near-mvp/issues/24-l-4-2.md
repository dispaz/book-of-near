# 24: Lesson 4.2: Swap across chains with an intent

**What to build:** The learner sees live tokens and a dry-run quote with solvers competing. If the connected mainnet account has funds, the lesson offers an optional tiny real swap with a hard cap and an explicit confirmation; otherwise it stays on the dry-run quote. The API key stays in the Worker. In demo mode a recorded quote is used. Records whether the real swap was completed, for the final badge rarity. Ends with an honest take on intents compared with other intent systems.
