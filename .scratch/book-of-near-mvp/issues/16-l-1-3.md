# 16: Lesson 1.3: Inside a NEAR transaction

**What to build:** The learner stacks several actions (create a sub-account, send NEAR, add a key) into one transaction, forces one action to fail and sees everything roll back together. The nonce and the recent block hash fields are shown and explained. Ends with an honest take on batched actions compared with one call per Ethereum transaction.
