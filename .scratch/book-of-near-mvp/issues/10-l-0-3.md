# 10: Lesson 0.3: Send a transaction and watch it

**What to build:** The learner sends a transfer from the practice account. An animated pipeline (build, sign, broadcast, include in a block, final) lights up from the real status responses on testnet and from recorded timings in demo mode. It stays generic: no shards or NEAR-specific detail yet. Ends with a link to the transaction in a block explorer on testnet and an honest take.
