# 11: Badge art system

**What to build:** Generate the badge art in code: five distinct stage icons (stages 0 to 4) and a final badge with four rarity tiers (common, rare, epic, legendary), all in the ink style of the book. Images are produced as static files with a content hash, and a preview page lists them. No paid design tool or hosting is needed.

**Blocked by:** 01 (Walking skeleton on the live URL)

**Status:** ready-for-agent

**Priority:** P0

- [ ] Five visibly different stage icons and four visibly different rarity tiers are generated by one command
- [ ] Each image has a recorded hash that the contract metadata can use
- [ ] A preview page shows all badges at small and large sizes in light and dark themes
- [ ] The icons read clearly at 64 pixels
