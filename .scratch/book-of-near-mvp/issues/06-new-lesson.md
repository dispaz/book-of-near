# 06: Lesson template and new-lesson command

**What to build:** A documented lesson template (hook, concept, do, check, honest take) and a Claude Code command that scaffolds a new lesson from it: folder, manifest, spec stub, demo-mode behaviour and an end-to-end test. The command works for lessons that need the chain and for lessons that do not.

**Blocked by:** 05 (Opening quiz, routes, progress and table of contents)

**Status:** ready-for-agent

**Priority:** P1

- [ ] Running the command with a new lesson id creates a working placeholder lesson that appears in the menu
- [ ] The generated lesson has a failing-then-passing test stub and a demo-mode path
- [ ] The template text explains the honest-take requirement and the rule to mark uncertain claims
