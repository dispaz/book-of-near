# 19: Lesson 3.1: Deploy a contract in one click

**What to build:** The learner deploys a ready-made contract to their own sub-account, calls it, reads its state and triggers a failing callback. No Rust toolchain is needed. The storage deposit for the code is explained. Ends with an honest take on Wasm contracts and in-place upgrades compared with Ethereum.
